# Standard 8×8 Chess — TD(0) Learning Starter

This version uses **temporal-difference learning (TD(0))**, not AlphaZero policy-target training.
It trains a value network from transitions generated by self-play. The model predicts the expected outcome from the current side-to-move perspective.

## Contents
- `model.py`: value-only residual neural network.
- `td_learning.py`: self-play, TD(0) bootstrap targets, replay buffer, checkpoint/resume.
- `play.py`: play against the value network using one-ply candidate evaluation.
- `evaluate.py`: inspect move values.
- `visualize.py`: board and TD-loss/progress plots.
- `config.py`, `chess_utils.py`, `requirements.txt`.
- `Chess_TD_8x8_Kaggle.ipynb`: notebook starter.

## TD(0) target and sign convention
The network value is from the perspective of the side to move. Since each chess move switches sides, for nonterminal transitions the one-step target is:
`target = reward - gamma * V(next_state)`.
At terminal transitions, the bootstrap term is zero and reward is the outcome from the perspective of the player who made the move. This starter is intentionally small and not expected to be strong immediately.

## Limitations / research notes
- This is a TD(0) value-learning scaffold, not a finished strong chess engine.
- The current behavior policy is simple one-ply value-guided self-play with 20% random exploration; it does not yet use MCTS. This isolates TD learning and is a good starting point for debugging.
- For a stronger project, consider TD(lambda), eligibility traces, prioritized replay, stronger opponent pools, a carefully tested reward/sign convention, and a fixed alpha-beta baseline evaluation.
- The model's value output is not proof of tactical correctness. Test mate positions and compare against a baseline under fixed time budgets.
- Save checkpoints and replay data outside the temporary Kaggle runtime before disconnecting.
